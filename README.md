# Platform FE

## Tech Stack

- React
- TypeScript
- Vite
- Refine
- MUI
- React Router
- React Hook Form
- Yup
- Day.js

## Requirements

- Node.js 18+
- npm 9+

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Create a `.env` file based on `.env.example` and define the required Vite environment variables.

## Project Structure

```text
src/
  assets/
  components/
  config/
  constants/
  hooks/
  providers/
  routes/
  services/
  theme/
  types/
  utils/
  App.tsx
  main.tsx
```
